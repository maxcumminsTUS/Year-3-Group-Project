# CNCS 3 Group Project – Munster Sport

## Overview

This is a group project for **Computer Networks & Cybersecurity 3** at TUS.

The project involves designing, developing and implementing a network solution for **Munster Sport**, including a company network, website, servers, security and backup systems.

## Project Stages

- **Stage 1:** High-Level Design
- **Stage 2:** Detailed Design
- **Stage 3:** Network Development & Implementation
- **Stage 4:** Customer Validation & Presentation
- **Stage 5:** Personal Contribution
